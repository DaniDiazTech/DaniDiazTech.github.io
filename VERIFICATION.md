## Scope of verification

The iframe integration test uses a controlled provider response to avoid making correctness depend on YouTube availability. Provider URLs and creator metadata were separately researched; actual video streaming may be blocked by regional, network, or embedding policy. Apple-hosted videos open on Apple’s site.

Mobile is Chromium emulation, not physical iPhone Safari. The in-app browser host was unavailable. Full Metal hosts, MLX experiments, larger training runs, and open-weight assistants are student assignments; they were not silently run or represented as completed capstones. The Metal kernel starter is not a tested complete GPU program. No model throughput is attributed to the user’s M5 Pro without measurement.

## Executable exercise upgrade

The coding bench contains 38 mini-labs associated with all 60 lessons. The native Clang challenge runner compiles all 38 starters and all 38 references from the exact same harness builder used in the browser. Every reference passes; every starter requires implementation.

Unit coverage now includes draft/backup compatibility, stale-result invalidation, incomplete check reports, and challenge metadata/lesson coverage. Browser coverage uses the real vendored compiler, not a mock compiler response: editable code, failed assertions, passing code, draft persistence, syntax diagnostics, infinite-loop watchdog, Stop, retry, and a representative vector/string/math/attention/reference matrix. Existing lesson/video integration tests still use the controlled YouTube response described above.

Runtime assets are self-hosted by Pages and verified against `public/compiler/vendor/manifest.json`. The runtime is pinned, retains its upstream license/notice, and includes memfs sources plus rebuild instructions. First use is opt-in; about 28 MB compressed downloads before local compilation. Full GPU, thread, exception, and native filesystem capabilities are outside this WASI runner. See `docs/EXECUTION_OPTIONS.md`.

Upgrade check totals: **14 unit tests**, **17 passing production-build browser scenarios** with one intentionally skipped duplicate mobile compiler-matrix scenario, and **38 native C++ mini-lab reference/starter pairs**. The real browser editor tests also export, reset, and import coding drafts and stale-result metadata. Four runtime binaries pass raw and compressed SHA-256 integrity checks.
